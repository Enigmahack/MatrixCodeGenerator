## CellGrid Enums

### CELL_STATE
`INACTIVE: 0`, `ACTIVE: 1`

### RENDER_MODE
`STANDARD: 0` (mix primary+secondary), `OVERLAP: 1` (both visible), `ADDITIVE: 2`

`NONE: 0`, `CHAR: 1`, `SOLID: 2`, `FULL: 3` (shadow), `DUAL: 5` (blend old+shadow)

## Config API
```javascript
config.get(key) → value
config.set(key, value) → void       // triggers save + notify
config.subscribe(callback) → void   // callback(key, state)
config.notify(key) → void
config.save() → void                // debounced localStorage
config.updateDerivedValues() → void
config.clearShaderState() → void
```
Storage keys: `matrix_config_v8.5`, `matrix_slots_v8.5`
